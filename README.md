This is an entry for the **Funniest Cat Voicemail Greeting** bounty on make.fun
(`u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443`).

Running `main.ts` (Node 22, standard library only) produces a single
humorous line in `/output/entry.txt` — or in
`$MAKEFUN_OUTPUT_DIR/entry.txt` if that variable is set:

> You've reached Biscuit. I can't come to the phone — I'm stuck in a box I chose. Leave a message; I'll sit on it later.

118 characters, 120 bytes (121 with the trailing newline), one greeting.
Because the line never changes, every run yields identical output:
there is no clock, no randomness, no network, and no external files
involved. The program refuses any entry outside 1–120 characters, then
reads the written file back to confirm the bytes stored are exactly
the gated string.

Why this line won the pick: Biscuit leaves his own voicemail from
inside a box he picked himself — his own fault, nobody else's — and
says he will sit on your message later, just as a cat sits on
everything else. The punchline arrives in the last five words, the
humour leans on cat behaviour in two separate ways (boxes, and sitting
on things), and the phrasing avoids the usual tropes entirely: no
"purr", no "meow", no nine lives, no "you're welcome". When this was
built, the competition leaderboard was empty (blind rounds, round 1
not yet judged), so there was no rival text to compare against; a web
search for the exact phrase returns 0 verbatim hits.
